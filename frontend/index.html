testd

Local dev domain manager

DNS Resolver

testd runs a local DNS server so .test domains resolve to your machine. Setting this up requires administrator privileges.

This step is required: without it, no .test name resolves in a browser.

Certificate Authority

testd serves HTTPS with a local certificate authority. Browsers must trust its root certificate; installing it requires administrator privileges.

This step is required: without it, browsers reject testd's HTTPS certificates.

Operator Secret

Other machines request their own token on first run; approve them from the dashboard's Access card or with testd approve. This machine uses the secret automatically, and unattended clients can present it as TESTD_TOKEN.

Edit it to match a secret your unattended clients already use.
